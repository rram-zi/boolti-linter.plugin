## 🔥 Boolti Linter : UX Writing 검수 플러그인
이 플러그인은 디자인 작업 과정에서 발생하는 비일관적인 UX 라이팅 문제를 해결하여, 프로덕트의 Voice & Tone을 유지하고 디자인 검수 시간을 단축시키기 위해 만들어졌습니다.

<br/>

## 🤣 면책 조항
⚠️ 경고: 코드가 깨끗하지 않을 수 있음

이 프로젝트는 **코딩을 모르는 디자이너**가 AI(Gemini)와 함께 울고 웃으며 만든 결과물입니다.  
전문적인 개발 구조보다는 "동작하는 것"에 초점을 맞췄습니다. 

*Thanks to Gemini... You are my hero.*

<br/>

## ✨ 핵심 기능
**1. 지능형 규칙 시스템**
   - 단순한 단어 찾기를 넘어, 오류의 종류('문체 수정', '단어 수정')를 자동으로 그룹핑하여 보여줍니다.
   - 금지어, 문체, 버튼 텍스트 등 다양한 규칙을 적용하며, '공연 정보' 같은 명사구나 '업데이트' 같은 예외 케이스를 인지하여 불필요한 제안을 최소화합니다.

**2. 원클릭 자동 수정**
   - [수정 적용하기]: 클릭 한 번으로 Figma 텍스트의 기존 색상, 굵기 등 복잡한 스타일을 유지한 채 내용만 즉시 수정합니다.
   - [전체 적용]: 검출된 모든 오류를 단 한 번의 클릭으로 일괄 수정하여 반복 작업을 없애줍니다.

**3. 직관적 인터랙션**
   - 하이라이팅: 수정 제안 시, 변경된 부분만 시각적으로 강조하여 사용자의 빠른 의사결정을 돕습니다.
   - [무시하기]: 디자이너의 의도를 존중하고, 불필요한 제안을 목록에서 제거할 수 있는 유연성을 제공합니다.
   - [재검사]: 수정 작업 후, 첫 화면으로 돌아갈 필요 없이 즉시 다시 검사를 실행하여 작업의 연속성을 보장합니다.
     
<br/>

## ⚙️ 설치 방법
1. 사용할 PC에서 압축 파일을 다운로드 받습니다.
2. Figma 데스크탑 앱을 엽니다.
3. Plugins > Development > Import plugin from manifest 선택합니다.
4. 압축 해제한 폴더 안에 있는 manifest.json 파일을 선택합니다.

<br/>

## 📖 사용 방법
1. Figma에서 플러그인을 실행합니다.
2. 라이팅 검사를 원하는 프레임이나 텍스트를 선택합니다. (아무것도 선택하지 않으면 현재 페이지 전체를 검사합니다.)
3. [라이팅 검사하기] 버튼을 클릭합니다.
4. 검사 결과가 나타나면, 각 카드의 [수정 적용하기] 버튼을 누르거나, 헤더의 [전체 적용] 버튼을 눌러 한번에 수정합니다.
0. 특정 제안을 원하지 않을 경우, [무시하기] 버튼을 클릭하여 목록에서 제거할 수 있습니다.

<br/>

## 💻 개발 및 수정 방법

이 플러그인을 직접 수정하거나 빌드하고 싶다면 아래 절차를 따르세요.

1. 패키지 설치 <br/>
yarn install
2. 룰 수정하기 (src/rules.ts) <br/>
새로운 금지어, 어미 변환 규칙, 예외 케이스 등을 이곳에서 추가할 수 있습니다.
3. 빌드하기 <br/>
수정한 내용을 반영하려면 다시 빌드해야 합니다. <br/>
yarn build

<br/>

## 📚 룰 관리 (rules.ts)
이 플러그인의 모든 검사 규칙은 src/rules.ts 파일에서 중앙 관리됩니다. <br/>
새로운 금지어를 추가하거나, 어미 변환 규칙, 버튼 텍스트 예외 규칙 등을 수정하고 싶을 경우 이 파일을 직접 편집한 후 다시 빌드하면 됩니다.
